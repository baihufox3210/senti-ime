# SentiIME Logo

![SentiIME](senti-ime.svg)

以台灣注音 **ㄅ** 與英文 **a** 並列，呈現中英混打；開放的幾何筆畫呼應輸入與接續文字。
深藍底色搭配薄荷綠注音與霧白英文，讓兩種輸入語言容易辨認。

- `senti-ime.svg`：128 × 128，透明外緣與深色圓角底，適用應用程式圖示、文件及 Linux 輸入法清單。
- `senti-ime-symbolic.svg`：24 × 24，透明底、`currentColor` 單色，適用工具列與支援 symbolic icon 的桌面主題。

兩個 SVG 都直接使用幾何向量路徑，沒有外部字型、點陣圖、腳本或遠端資源。
彩色版建議最小 24 px，單色版建議最小 16 px；保留 viewBox 外緣的留白，勿拉伸比例。

| 色彩 | 色碼 |
|---|---|
| 深藍 | `#142B38` |
| 薄荷綠 | `#65E3BD` |
| 霧白 | `#F3F8F7` |

另提供 `png/` 中 16–256 px 的 PNG 相容版本，皆由原始 SVG 渲染，避免桌面缺少 SVG 圖示載入支援而顯示破圖。

Linux 建置會把 SVG 與 PNG 圖示安裝到 hicolor 主題，Fcitx5 四種方案共用 `senti-ime` 圖示。
實際狀態列仍可能優先顯示 Fcitx 的模式文字標籤，取決於桌面主題與面板設定。
